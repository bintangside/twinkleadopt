TWINKLE ADOPT — UPDATED WEBSITE

Isi paket:
- index.html
- style.css
- script.js
- assets/ (illustrasi produk original yang dibuat konsisten satu visual style)

BACKSOUND:
1. Siapkan file MP3 milikmu.
2. Rename menjadi: bgm.mp3
3. Masukkan ke folder: assets/
4. Upload seluruh folder ke GitHub Pages.
5. Klik tombol ♫ di website untuk memutar/mematikan musik.
Catatan: browser biasanya memblokir autoplay bersuara, jadi musik dimulai saat pengunjung menekan tombol ♫.

BAHASA:
ID, EN, dan FR sekarang menerjemahkan seluruh bagian utama website dan tetap memakai desain yang sama.

FOTO PRODUK:
Versi ini memakai ilustrasi original bergaya studio yang dibuat konsisten antarproduk, agar jenis boneka sesuai dengan namanya dan visual website tidak terlihat seperti kumpulan foto acak. Jika kamu sudah punya foto produk asli, file SVG di assets bisa diganti dengan JPG/PNG milikmu tanpa mengubah layout.

GITHUB PAGES:
Upload index.html, style.css, script.js, folder assets, dan README.txt.
