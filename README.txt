BACKSOUND
---------
A music button has been added.
To use your own music:
1. Put your MP3 file in the same folder as index.html.
2. Rename it to: backsound.mp3
3. Open the website and click the ♫ button.
The button is intentionally click-to-play because browsers often block autoplay with sound.
